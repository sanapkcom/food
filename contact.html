📌 Quick Help

🍽️ Adding a spot — You need to be logged in. Click "Add Place" in the navbar.

📍 Distance not showing? — Allow location access when the browser asks.

🖼️ Image upload — Make sure your Supabase "spot-images" storage bucket is set to public.

✏️ Edit/Delete — Only the person who added a spot can edit or delete it.

🚩 Report a spot — Open any spot's detail page and tap "Report".
